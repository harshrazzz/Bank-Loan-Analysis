# Bank Loan Analysis Dashboard

## Project Overview

This project analyzes bank loan data using Python. The aim was to calculate important lending metrics, compare good and bad loans, and visualize trends in loan applications, funding, and repayments.

## KPIs Calculated

* Total Loan Applications
* Total Funded Amount
* Total Amount Received
* Average Interest Rate
* Average Debt-to-Income Ratio (DTI)

### Good Loan Analysis

* Good Loan Percentage
* Good Loan Applications
* Good Loan Funded Amount
* Good Loan Amount Received

### Bad Loan Analysis

* Bad Loan Percentage
* Bad Loan Applications
* Bad Loan Funded Amount
* Bad Loan Amount Received

## Visualizations

* Monthly Trends by Issue Date
* Regional Analysis by State
* Loan Term Distribution
* Employment Length Analysis
* Loan Purpose Breakdown
* Home Ownership Analysis

## Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Key Findings

* Identified monthly patterns in loan applications and funding.
* Compared the performance of good and bad loans.
* Analyzed borrower characteristics such as employment length and home ownership.
* Examined regional differences in lending activity.
